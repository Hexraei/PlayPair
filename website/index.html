Features

Everything you need.
Nothing you don't.

PlayPair does one thing — keeps two people's media perfectly in lockstep — and it does it well.

Real-time sync

Play, pause, seek — mirrored in milliseconds via SignalR WebSockets. No polling, no lag.

No sign-up

Skip the onboarding. No email, no passwords, no registration. Just download and start syncing instantly.

Privacy first

No media is uploaded. Sessions are ephemeral. When the room closes, nothing is retained.

How it works

Three steps to
watching together.

01

Host creates a room

Click the PlayPair tray icon and tap "Create Room". A unique 6-character code appears instantly — no server config, nothing.

02

Share the code

Copy the 6-character code and send it to your friend. Text, Discord, a sticky note — your call.

03

Press play

Start the media on both sides. The host's play, pause, and seek commands are mirrored in real-time — your friend stays locked in step.

Compatibility

If it plays, it syncs.

PlayPair hooks into the Windows Media Session API — the same layer your taskbar uses for playback controls. Any player that speaks it, PlayPair sees.
